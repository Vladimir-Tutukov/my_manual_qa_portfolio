### Описание
На главной странице сервиса https://yandex.ru/pogoda/ отображаются поисковая строка, с помощью которой можно вызвать отображение погоды для выбранного местоположения.
Для получения этого при нажатии на поисковую строку отображаются избранные локации для авторизованных пользователей. При вводе названия населённого пункта доступен переход на страницу прогноза для этого населённого пункта.

### Критерии приемки (Acceptance Criteria)
При нажатии на поисковую строку отображается поле ввода информации.
При нажатии на поисковую строку отображаются избранные локации, если пользователь авторизован.
При вводе текста в поисковую строку отображаются поисковые подсказки по населённым пунктам.
При выборе населённого пункта отображается погода для этого населённого пункта, а поисковая строка становится неактивной.
