### Описание пользовательской истории
Как пользователь я хочу иметь возможность посмотреть прогноз погоды на ближайшие дни для своего населённого пункта

### Ожидаемый результат (верхнеуровнево)
Пользователь может получить прогноз погоды с главной страницы сервиса
Пользователь видит прогноз сразу на несколько дней вперёд
Пользлватель может выбрать населённый пункт вручную
Пользователь может сохранить свой выбор
