---
### Описание пользовательской истории
Как пользователь я хочу иметь возможность посмотреть прогноз погоды для удалённого места даже если я не знаю его точного названия но знаю где оно расположено

### Ожидаемый результат (верхнеуровнево)
Пользователь может получить прогноз погоды для другого населённого пункта
Пользователь может выбрать место для получения прогноза
Прогноз должен учитывать местное время для удалённого места
