# Функционал временной шкалы для погодной карты "Карта осадков"


## Description

В документации карты осадков сказано следующее:
```markdown
Узнать тип облачности и интенсивность осадков в предыдущие и следующие 2 часа — выберите нужное время на временной шкале.
```
Здесь не указано что шкала ограничивается только 2 часами после текущего времени.

В требовании REQ-map-007 та же информация 

```markdown
На карте осадков представлена шкала на которой можно выбрать время на 2 часа до текущего времени и на 2 часа позже.
```

В тест кейсах TC-map-014 и TC-map-15 

указан ожидаемый результат 
```markdown
Крайнее правое положение соответствует времени на 2 часа позднее текущего времени. Отображается карта осадков для выбранного времени
```
требуется внести исправление в тест кейсы TC-map-014 и TC-map-15 - вместо *Крайнее правое положение соответствует времени на 2 часа позднее текущего времени* указать
*Крайнее правое положение соответвует времени позднее текущего и отличается от него не менее чем на 2 часа*

## STR

Ожидаемый результа:
1) тест кейс TC-map-014 соответствует требованию REQ-map-007
2) тест кейс TC-map-015 соответствует требованию REQ-map-007

Фактический результат:
ожидаемый результат для пункта 5. тест кейсов 
```markdown
5. Переместить ползунок на временной шкале в крайнее правое положение
```
не соответствует требованию REQ-map-007
