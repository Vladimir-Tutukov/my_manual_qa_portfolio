### Предусловия (Preconditions)
1. Браузер открыт в режиме инкогнито (для yandex browser) или приватного просмотра (firefox)
2. Открыта страница https://pogoda.yandex.ru/
3. Браузер переключен в отображение данных для мобильного устройства.

### Шаги (Steps)
1. Нажать на кнопку "Карта осадков"
2. Проверить текущую погоду и цвет шкалы - при наличии облаков линия должна быть голубой, для ясной погоды - желтой
3. Нажать на время на временной шкале
4. Переместить ползунок на временной шкале в крайнее левое положение
5. Переместить ползунок на временной шкале в крайнее правое положение



### Таблица ожидаемых результатов (Expected Result)
Здесь перечисляются шаги тест кейса и результаты к которым приводит каждый из них. таблица  заполняется в формате:
| № | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Нажать на кнопку "Карта осадков" | Открылась карта осадков. |
| 2 | Проверить текущую погоду и цвет шкалы - при наличии облаков линия должна быть голубой, для ясной погоды - желтой | На странице отображается шкала цвет которой желтый если ясно и голубой если есть облака |
| 3 | Нажать на время на временной шкале | Отображается карта осадков для выбранного времени |
| 4 | Переместить ползунок на временной шкале в крайнее левое положение | Крайнее левое положение соответствует времени на 2 часа ранее текущего времени. Отображается карта осадков для выбранного времени |
| 5 | Переместить ползунок на временной шкале в крайнее правое положение | Крайнее правое положение соответствует времени на 2 часа позднее текущего времени. Отображается карта осадков для выбранного времени |

### Вариации (Variations)
Для мобильной версии браузера:
После открытия страницы нужно убедиться что открыта мобильная версия - в противном случае нужно переключить переключатель в меню браузера "версия для ПК" в положение "ВЫКЛ"

Для десктопной версии браузера:
После открытия страницы нужно открыть dev tools и выбрать toggle device toolbar и указать одно из мобильных устройств.
Для этого теста используется шаблон разрешения экрана для устройства iphone 14.
