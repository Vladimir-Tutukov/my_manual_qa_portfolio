### Предусловия (Preconditions)
1. Браузер открыт в режиме инкогнито (для yandex browser) или приватного просмотра (firefox)
2. Открыта страница https://pogoda.yandex.ru/

### Шаги (Steps)
1. Нажать на кнопку "Карта осадков"
2. На верхней шкале нажать кнопку "Давление"
3. Проверить что внизу карты отображается шкала давления
4. Проверить масштабируемость карты - уменьшить масштаб с помощью колеса мыши
5. Навести курсор на другое место на карте
6. Нажать на это место.
7. Нажать на данные о ветре над маркером



### Таблица ожидаемых результатов (Expected Result)
Здесь перечисляются шаги тест кейса и результаты к которым приводит каждый из них. таблица  заполняется в формате:
| № | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Нажать на кнопку "Карта осадков" | Открылась карта осадков. На странице отображается шкала содержащая кнопки "Осадки", "Температура", "Ветер", "Давление" |
| 2 | На верхней шкале нажать кнопку "Давление" | Открылась карта атмосферного давления |
| 3 | Проверить что внизу карты отображается шкала давления | Шкала отображается, красным цветом обозначены зоны с высоким давлением, синим- с низким |
| 4 | Проверить масштабируемость карты - уменьшить масштаб с помощью колеса мыши | Карта отображается в другом масштабе, на карте отображается больше цветов соответствующих разной величине атмосферного давления |
| 5 | Навести курсор на другое место на карте | Рядом с курсором отображается информация по атмосферному давлению для этого места |
| 6 | Нажать на это место. | Маркер переместился на это место. Над маркером отображается информация по атмосферному давлению выбранного места |
| 7 | Нажать на данные о давлении над маркером | Открылась главная страница. Отображается погода для места выбранного на карте |

### Вариации (Variations)
Для мобильной версии браузера есть дполнительный шаг.
После открытия страницы нужно убедиться что открыта полная версия - в противном случае нужно переключить переключатель в меню браузера "версия для ПК" в положение "ВКЛ"
