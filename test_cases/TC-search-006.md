### Предусловия (Preconditions)
1. Браузер открыт в режиме инкогнито (для yandex browser) или приватного просмотра (firefox).

### Шаги (Steps)
1. Открыть страницу https://yandex.ru/pogoda/
2. Проверить отображение поисковой строки
3. Нажать на поисковую строку
4. Набрать текст "Vjcrdf"
5. Нажать на поисковую подсказку "Москва"


### Таблица ожидаемых результатов (Expected Result)
Здесь перечисляются шаги тест кейса и результаты к которым приводит каждый из них. таблица  заполняется в формате:
| № | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Открыть страницу https://yandex.ru/pogoda/ | Страница успешно загрузилась |
| 2 | Проверить отображение поисковой строки | На странице отображается поисковая строка |
| 3 | Нажать на поисковую строку | В поисковой строке мигает каретка ввода, отображается окно с популярными городами |
| 4 | Набрать текст "Vjcrdf" | Появились поисковые подсказки с населёнными пунктами с похожим на "москва" названием |
| 5 | Нажать на поисковую подсказку "Москва" | Поисковые предложения пропали, отображается страница прогноза погоды для города Москва |

### Вариации (Variations)
- при тестировании десктопной версии:

Для мобильной версии браузера есть дполнительный шаг.
После открытия страницы нужно убедиться что открыта полная версия - в противном случае нужно переключить переключатель в меню браузера "версия для ПК" в положение "ВКЛ"

- При тестировании мобильной версии:

Для мобильной версии браузера:
После открытия страницы нужно убедиться что открыта мобильная версия - в противном случае нужно переключить переключатель в меню браузера "версия для ПК" в положение "ВЫКЛ"

Для десктопной версии браузера:
После открытия страницы нужно открыть dev tools и выбрать toggle device toolbar и указать одно из мобильных устройств.
Для этого теста используется шаблон разрешения экрана для устройства iphone 14.
