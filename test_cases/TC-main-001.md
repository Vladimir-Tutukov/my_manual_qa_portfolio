### Предусловия (Preconditions)
1: Браузер открыт в режиме инкогнито (для yandex browser) или приватного просмотра (firefox)


### Шаги (Steps)
1. Открыть страницу https://yandex.ru/pogoda/
2. Проверить наличие фактического и почасового прогноза погоды
3. Для фактического прогноза проврить отображение: температуры, скорости и направление ветра, атмосферного давления, влажности воздуха.
4. Для почасового прогноза проверить отображеие погоды и температуры.
5. Для почасового прогноза проверить наличие информации о времени восхода и заката без указания температуры.
6. Проверить наличие краткого и подробного прогноза на 10 дней
7. Для краткого прогноза проверить отображеие информации о погоде и температуре для дня и ночи для каждого из дней.
8. Для подробного прогноза проверить отображеие информации о погоде, температуре, скорости и направлении ветра, атмосферном давлении и влажности воздуха для утра, дня, вечера и ночи для каждого из дней
