### Предусловия (Preconditions)
1. Браузер открыт в режиме инкогнито (для yandex browser) или приватного просмотра (firefox)
2. В браузре открыта страница https://yandex.ru/pogoda/
3. Браузер переключен в отображение данных для мобильного устройства.


### Шаги (Steps)
1. Проверить наличие фактического и почасового прогноза погоды
2. Для фактического прогноза проврить отображение: температуры, скорости и направление ветра, атмосферного давления, влажности воздуха.
3. Для почасового прогноза проверить отображеие погоды и температуры.
4. Для почасового прогноза проверить наличие информации о времени восхода и заката без указания температуры.
5. Проверить наличие краткого и подробного прогноза на 10 дней
6. Для краткого прогноза проверить отображеие информации о погоде и температуре для дня и ночи для каждого из дней.
7. Для подробного прогноза проверить отображеие информации о погоде, температуре, скорости и направлении ветра, атмосферном давлении и влажности воздуха для утра, дня, вечера и ночи для каждого из дней

### Вариации (Variations)
Для мобильной версии браузера:
После открытия страницы нужно убедиться что открыта мобильная версия - в противном случае нужно переключить переключатель в меню браузера "версия для ПК" в положение "ВЫКЛ"

Для десктопной версии браузера:
После открытия страницы нужно открыть dev tools и выбрать toggle device toolbar и указать одно из мобильных устройств.
Для этого теста используется шаблон разрешения экрана для устройства iphone 14.
