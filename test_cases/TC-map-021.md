### Предусловия (Preconditions)
1. Браузер открыт в режиме инкогнито (для yandex browser) или приватного просмотра (firefox)
2. Открыта страница https://pogoda.yandex.ru/
3. Браузер переключен в отображение данных для мобильного устройства.

### Шаги (Steps)
1. Нажать на кнопку "Карта осадков"
2. На верхней шкале нажать кнопку "Осадки"
3. В отобразившемся списке нажать "Давление"
4. Проверить что внизу карты отображается шкала давления
5. Проверить наличие переключателя "анимация ветра"
6. Уменьшить масштаб жестами или с помощью колеса мыши
7. Нажать на другое место на карте
8. Нажать на данные о давлении над маркером

### Таблица ожидаемых результатов (Expected Result)
Здесь перечисляются шаги тест кейса и результаты к которым приводит каждый из них. таблица  заполняется в формате:
| № | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Нажать на кнопку "Карта осадков" | Открылась карта осадков. На странице отображается кнопка "Осадки" |
| 2 | На верхней шкале нажать кнопку "Осадки" | На странице появился список, содержащй кнопки "Осадки", "Температура", "Ветер", "Давление" |
| 3 | В отобразившемся списке нажать "Давление" | Отображается карта атмосферного давления|
| 4 | Проверить что внизу карты отображается шкала давления | Шкала отображается, красным цветом обозначены зоны с высоким давлением, синим- с низким |
| 5 | Проверить наличие переключателя "анимация ветра" | внизу страницы слева отображается переключатель "анимация ветра" |
| 6 | Уменьшить масштаб жестами или с помощью колеса мыши | Карта отображается в другом масщтабе, на карте отображается больше цветов соответствующих разному атмосферному давлению |
| 7 | Нажать на другое место на карте | Маркер переместился на это место. Над маркером отображается информация по атмосферному давлению выбранного места |
| 8 | Нажать на данные о давлении над маркером | Открылась главная страница. Отображается погода для места выбранного на карте |

### Вариации (Variations)
Для мобильной версии браузера:
После открытия страницы нужно убедиться что открыта мобильная версия - в противном случае нужно переключить переключатель в меню браузера "версия для ПК" в положение "ВЫКЛ"

Для десктопной версии браузера:
После открытия страницы нужно открыть dev tools и выбрать toggle device toolbar и указать одно из мобильных устройств.
Для этого теста используется шаблон разрешения экрана для устройства iphone 14.
